# Student Management System

This is a simple Student Management System made using Python.

I created this project to practice Python file handling, loops, conditional statements, and taking input from the user. The program stores student details in a text file and allows us to view, search, and count students.

## Features

The program can:

* Add student details
* Display all students
* Search for a student by name
* Count the total number of students
* Exit the program

## Student Details

For each student, the program stores:

* Roll Number
* Name
* Fee

The details are saved in a file called `students.txt`.

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or Terminal.
4. Run the Python file:

```bash
python student.py
```

The `students.txt` file will be created automatically when you add the first student.

Student details are stored like this in `students.txt`:

```text
101,Sai,25000
102,Rahul,30000
103,John,28000
```
